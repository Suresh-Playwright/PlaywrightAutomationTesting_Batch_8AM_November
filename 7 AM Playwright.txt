What is TypeScript ?

JavaScript is a programming langauge used to develop dynamic and interactive web applications

For example:

1. When we click a Login Button , some action happens
2. When we enter username and password the application processes the information
3. When we click Submit , the application validates the details

All these details or functionalities can developed by JavaScript.


What is Type Script ?

Typescript is a programming language developed by Microsoft it is built on top of JavaScript.

In Simplewords , Typescript is JavaScript with additional features , especially static type checking.

It helps developers identify certain errors during the developmenet rather thant discovering them only when the application runs.

One Important Point :  Browsers do not direcctly execute TypeScript , Typescript code is converted into JavaScript compiler.

JavaScript Code :

let username= "John";

username=100;

console.log(username); // 100


JavaScript allows us the assign a number to the variable even though it initially contained  stringg.

TypeScriptCode:

let username: string= "John";

username=100;

console.log(username); // error


Here , Typescript identifies a type mismatch because we declared username as string.

*** Typescript help us catch type realted mistakes during development.

var in TypeScript:
------------------

var is one of the oldest ways to declare variables in JavaScript and TypeScript

We can declare a variable using the var keyword.


We can also assigne its value and redeclare it within the same scope.

var username: string="John";
console.log(username)
username= "David"
console.log(username)
// Redeclaration
var age:number=25;
var age:number =27;
console.log(age)

var is a function scoped , not block scoped

This means a variable declared inside an if block can also be accessed outside that block , provided it is with in the same function.

For modern typescript : prefer let and const instead of var.

let in TypeScript :

We use let when we want to declare a variable whose value may change during program execution.
For example , imagine we are testing a login application

Intially , the login status is false.

After entering valid credentials , the login status becomes true

So the value changes during the execution . In  this situation we can use let.

let loginStatus: boolean= false;
console.log(loginStatus)

loginStatus=true;
console.log(loginStatus)

const in TypeScript:
--------------------

We use const when we don't want to re-assign a variable after intialization.

For example: consider the application URL used in  our automation framework

We generally don't want to change this URL accidently during test execution.
So we can declare it using const..

// can we redeclare a let variable in the same scope
// No
// let age: number=25;
// let age: number=27;

// var age1:number=25;
// var age1:number=27;




// BLOCK SCOPE

// if(true)
// {
//     let  city: string= "Hyd";
//     console.log(city)
// }
// console.log(city)

const applicationURL: string= "https://www.google.com"
console.log(applicationURL)

// can we reassign a const variable ?

// No
const age=25;
age=30;
console.log(age)

// can we declare const without initializing it ?
const username: string;
// No




1. Use const when re-assignment is not required
2. Use let when the value needs to change
3. Avoid var in modern TypeScript projects.

Abstraction :
Abstraction is the process of hiding internal implementation details and showing only
essential functionality to the user.


We tell the user WHAT an object can do.
We hide HOW that functionality is implemented Internally.




How do you Implement Abstraction ?

TypeScript supports abstraction primarily through:

1. Abstraction Classes
2. Interfaces


Abstract Classes :

An Abstract class is a class that cannot be instantiated directly.

It is designed to be inherited by other classes.


abstract class ClassName{

    abstract methodName(): void;
    normalMethod():void { console.log("Normal Method")}
}


1. Use the abstract keyword
2. You cannot create an object of an abstract class
3. An abstract class contain abstract methods
4. It can also contain implemented methods.
5. Child Classes must implment inherited abstract methods
6. Abstract classes can have constructors and properties


Example 1 :  Vehicle Abstraction

Requirement :

Every Vehicle should start its engine , but each Vehicle has its own engine starting 
implementation.

abstract class Vehicle
{
    abstract startEngine(): void;

    stopEngine(): void{
        console.log("Engine Stopped")
    }
}
class Car extends Vehicle
{
    startEngine(): void {
        console.log("Car Engine Started")
    }
}

class Bike extends Vehicle
{
    startEngine(): void {
        console.log("BIKE Engne Started")
    }
}
// Creating Objects

const car = new Car()
car.startEngine()
car.stopEngine()
const bike= new Bike()
bike.startEngine()
bike.stopEngine()


1. Vehicle is an abstract class.
2. startEngine() is an abstract method
3. stopEngine() is  a normal method.
4. Car and Bike Inheirtance the Vehicle classes
5. Each child class provides its own implementation of startEngine()


Interface :

An interface defines the structure or contract that class must follow.

It tells us which properities and methods are required , without providing their
implementation.
